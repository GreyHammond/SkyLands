Features

A home above the clouds

SkyLands gives every player a personal island in a world of its own, built from real terrain and connected to your normal survival world.

Five island sizes

From a cosy 32×32 Small island to a 512×512 Continental. Upgrade any time and the border grows with you.

Grows biome by biome

New land attaches to your island's edge. Unlock a cherry grove, a desert or a snowy taiga as its own region.

Jump to the overworld

Step off the edge and fall out of the sky, landing somewhere below your island. Open an elytra mid-fall to steer.

You set the rules

Let visitors use doors but not chests. Let friends harvest crops but not break blocks. Every option is a toggle.

One menu for everything

Type /skyland. Single-tap chest menus work the same on Java and on Bedrock through Geyser.

Real terrain

Admins capture spheres of terrain from your own worlds. Islands keep their grass colour, sky and music.

How it plays

From first island to continent

The whole loop lives in one menu. Nothing to type, no items to lose.

Buy an island

Pick a size, pick a biome, confirm. Your island rises from the clouds and you're teleported onto it.

Grow it outward

Add more land of a biome you own, or unlock a new biome. It attaches to the edge as its own region, and the island stays one connected landmass.

Fall to the world below

Jump off the edge. You land up to 200 blocks from directly below your island, and the landing that ends the fall does no damage.

Ride the wind home

Return to Island launches you up on a gust of wind and carries you back home a second later.

The menu

Everything in /skyland

Three buttons at the top. Everything else lives one tap deeper. Anything that costs money asks you to confirm first.

Skyland

Return to Island: fly home, or visit friends' and public islands. Shows Buy an Island if you don't have one yet.
Manage Island: grow, unlock biomes, upgrade, protection, friends.
Delete Island: two confirmations, then it crumbles into the clouds.

Island settings

Apply to the whole island: open to visitors (on), PvP, explosion damage, fire spread and mob griefing (all off).

Farm-friendly

Harvesting is separate from breaking. Friends can pick and replant your crops without being able to touch your build.

Setup

Up and running in minutes

For server owners running Paper 26.3 on Java 25.

Install

Drop skylands.jar into plugins/. Optional: Vault plus an economy plugin. Without one, islands are free, which is handy for testing.

Start the server

An empty sky world, skyrealms_sky, is created automatically. Multiverse is optional.

Capture biomes

Stand in a biome and run /skylandadmin capture cherry_grove 16. Grab 4–5 spots per biome for variety.

Let players in

Players type /skyland and buy their first island.

Admin commands

/skylandadmin preview <radius>                 show the capture sphere
/skylandadmin capture <biome> <radius> [name]  save terrain as a piece
/skylandadmin pieces                           list biomes and variants
/skylandadmin give <player> <size> <biome>     free island
/skylandadmin tp <player>                      go to an island
/skylandadmin rebuild <player>                 re-paste an island
/skylandadmin reload                           reload piece files

Build from source

./gradlew build      # requires JDK 25; jar lands in build/libs/skylands.jar
Geyser + Floodgate: every screen uses plain single-tap chest menus with no typing, so Bedrock players get the same experience as Java players. Friends are picked from a list of online players.
